## 🚀 البدء السريع

### المتطلبات

- Node.js 18+
- npm أو yarn
- [Google Gemini API Key](https://aistudio.google.com/apikey) (مجاني)

### التثبيت

```bash
# 1. استنساخ المشروع
git clone https://github.com/yessur43-rgb/ZAD.git
cd ZAD

# 2. تثبيت التبعيات
npm install

# 3. تشغيل التطبيق
npm run dev

# 4. فتح المتصفح على
# http://localhost:5173
```

### البناء للإنتاج

```bash
npm run build
```

## 📖 الأدوات التسعة

### 1️⃣ تحليل المنتج (Image Analyzer)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** تحليل صور المنتجات للتحقق من حلال/حرام

**الميزات:**
- ✅ رفع صورة من المعرض
- ✅ التقاط صورة مباشرة
- ✅ مسح باركود
- ✅ تقييم صحي شامل
- ✅ الأدلة الشرعية

**كيف تستخدمها:**
1. اضغط على "تحليل المنتج"
2. اختر طريقة إدخال (صورة/كاميرا/باركود)
3. انتظر التحليل (5-10 ثواني)
4. اقرأ النتيجة: ✅ حلال / ❌ حرام / ⚠️ مشبوه

</details>

### 2️⃣ ابحث عن أماكن (ChatBot)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** بحث ذكي تفاعلي عن أماكن قريبة

**الفئات:**
- 🍽️ مطاعم حلال
- ☕ مقاهي
- 🛍️ تسوق
- 💊 صيدليات
- 🏛️ معالم سياحية

**الميزات:**
- محادثة تفاعلية مع AI
- ترتيب حسب المسافة أو التقييم
- عرض على خريطة تفاعلية
- إضافة للمفضلة

</details>

### 3️⃣ أوجدها لي (FindIt)

<details>
<summary>اضغط للتفاصيل</summary>

**أداة ثلاثية الأغراض:**

**أ. البحث عن منتج:**
- صور منتج أو ابحث بالنص
- يجد متاجر قريبة تبيعه

**ب. معلومات الفيجنيت:**
- للسفر بالسيارة في أوروبا
- الأسعار وأماكن الشراء لكل دولة

**ج. ما هذا؟ (Identify):**
- صور أي شيء
- يتعرف عليه ويعطيك معلومات
- للأماكن: معلومات + Google Maps
- للمنتجات: أماكن الشراء

</details>

### 4️⃣ تحليل القائمة (Menu Analyzer)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** تحليل قوائم المطاعم

**كيف تعمل:**
1. صور قائمة المطعم
2. AI يقرأ جميع الأطباق
3. يصنفها: ✅ حلال / ❌ حرام
4. ملاحظات لكل طبق

**مفيد عند:**
- السفر لدول أجنبية
- المطاعم غير العربية
- عدم معرفة المكونات

</details>

### 5️⃣ الأنشطة (Activities Finder)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** اكتشف أنشطة وفعاليات في أي مدينة

**معلومات كل نشاط:**
- الاسم والوصف التفصيلي
- الفئة (رياضة، ترفيه، ثقافة...)
- الأسعار والتكاليف
- أوقات العمل
- الحالة (مفتوح/مغلق/يغلق قريباً)
- رابط Google Maps

</details>

### 6️⃣ على طريقي (On My Way)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** ابحث عن أماكن على طريق رحلتك

**كيف تعمل:**
1. حدد نقطة البداية (أو موقعك الحالي)
2. حدد الوجهة
3. اختر فئة: مطاعم 🍽️ / مقاهي ☕ / مساجد 🕌 / استراحات ⛽

**مثال:**
```
من: الرياض → إلى: جدة
البحث عن: مساجد
النتيجة: 12 مسجد على الطريق مع المسافات
```

</details>

### 7️⃣ دليل المكونات (Ingredient Guide)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** معلومات سريعة عن المكونات الغذائية

**ابحث عن:**
- E-numbers (مثل: E471، E120)
- أسماء المكونات (جيلاتين، ليسيثين)

**تحصل على:**
- اسم المكون الكامل
- المصدر (نباتي/حيواني)
- الحكم الشرعي
- نصائح مفيدة

</details>

### 8️⃣ مساحتي (MySpace)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** دفتر رحلات شخصي ذكي بالذكاء الاصطناعي

**الأقسام الستة:**
- 🏨 **السكن** - فنادق وشقق مع تقييمات
- 🍽️ **مطاعمي** - المطاعم التي زرتها
- 🏛️ **معالم زرتها** - أماكن سياحية
- 📸 **ذكريات** - لحظات خاصة
- 📝 **ملاحظات** - معلومات سريعة
- ⭐ **مهم** - أشياء مهمة جداً

**الميزات الذكية:**
- 🤖 تحليل AI تلقائي للصور
- 📍 استخراج الموقع بدقة GPS
- ✍️ أوصاف جميلة وشاعرية
- ⭐ تقييمات وملاحظات شخصية
- 📊 إحصائيات (الدول، المدن، الإجمالي)
- 💾 ضغط تلقائي للصور (توفير 85-95%)

**مثال:**
```
صورت برج إيفل
    ↓
AI يتعرف عليه تلقائياً
    ↓
يعطيك: الاسم الكامل + الموقع الدقيق + وصف تاريخي جميل
    ↓
تحفظه في "معالم زرتها"
```

</details>

### 9️⃣ المفضلة (Favorites)

<details>
<summary>اضغط للتفاصيل</summary>

**الوظيفة:** احفظ جميع أماكنك المفضلة

**تحفظ من:**
- ابحث عن أماكن
- أوجدها لي
- الأنشطة
- على طريقي

**الميزات:**
- فلترة حسب الفئة
- حذف سهل
- روابط Google Maps مباشرة
- تنظيم تلقائي

</details>
